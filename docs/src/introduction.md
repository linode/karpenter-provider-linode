# Karpenter Provider Linode

Karpenter Provider Linode enables Karpenter to provision capacity for Kubernetes workloads running on Linode Kubernetes Engine (LKE).

Use the [repository README](https://github.com/linode/karpenter-provider-linode/blob/main/README.md) for installation and a quick start.
